# 스냅 다이어리 (Snap Diary)

그날 한 일을 글과 사진으로 남기고, 다녀온 **장소 사진은 3D 공간으로** 다시 보는 나만의 폐쇄형 PWA 다이어리입니다.
기록은 휴대폰 안(오프라인 우선)에 먼저 저장되고, **내 Google Drive**로 동기화됩니다. 서버가 없고, 앱은 자신이 만든 파일만 볼 수 있습니다.

장소 사진의 3D 표현은 이 저장소의 [Meet Vanish](../meet-vanish-extension/)(/snap) 먼지 효과에서 왔습니다.
`grain-transport.js`의 GPU 그레인 방식(셀마다 GPU 점 하나 + 작은 조각 둘, 해시로 만든 분리 시점, 오른쪽으로 쏠린 바람·소용돌이, 역재생 재조립)을
그대로 가져와, 각 그레인을 사진의 **깊이(depth)** 위치에 놓은 3D 포인트 클라우드로 확장했습니다.

## 기능

- **기록**: 날짜, 기분, 제목, 글, 장소 이름·현재 위치, 사진 여러 장. 작성 중 뒤로 가기를 해도 자동 저장됩니다.
- **장소 사진 3D**: 사진 한 장에서 깊이를 추정해 3D로 만듭니다.
  - 열면 먼지가 모여 장면이 만들어지고, **스냅** 버튼을 누르면 Meet Vanish처럼 먼지로 흩어졌다가 다시 모입니다.
  - 드래그로 둘러보기, 두 손가락으로 확대/축소, **기울이기**(자이로), 깊이 강도 슬라이더.
  - 깊이는 기기 안에서 **Depth Anything V2(small)** AI 모델로 계산합니다. 모델을 쓸 수 없으면(오프라인 등) 간이 깊이로 대신하고, 나중에 "AI로 다시"를 누를 수 있습니다.
- **달력 / 장소 모아보기 / 검색**
- **Google Drive 동기화**: 여러 기기에서 같은 다이어리를 씁니다. 두 기기에서 동시에 고친 글은 어느 쪽도 버리지 않고 합칩니다.
- **오프라인**: 지하철에서도 쓰고 보며, 연결되면 자동으로 올라갑니다.
- **앱 잠금(PIN)**, 허용 계정 제한, 사진의 EXIF(위치 정보 포함) 제거.

### Google Drive에 저장되는 모습

```
내 드라이브/
  Snap Diary/
    entries/     2026-10-11_성수동 산책.json   ← 일기 1편 = JSON 1개
    photos/      2026-10-11_성수동 산책_1.jpg  ← 사진 원본(최대 2560px, Drive에서 바로 볼 수 있음)
    .app-data/   썸네일, 3D 깊이 지도(png)
```

## 설정 방법 (처음 한 번)

### 1. 앱 주소 만들기 — GitHub Pages

1. 이 브랜치를 기본 브랜치(main)에 병합합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions** 를 선택합니다.
3. **Actions** 탭의 *Snap Diary* 워크플로가 끝나면 주소가 생깁니다: `https://siree1223-sys.github.io/snap/`
   (워크플로가 Pages 설정 전에 실패했다면 *Snap Diary → Run workflow* 로 다시 실행하세요.)

> 비공개 저장소의 GitHub Pages는 유료 플랜(Pro 등)에서만 됩니다. 무료 플랜이라면 (a) 저장소를 공개로 바꾸거나 — 공개되는 것은 앱 코드뿐이고 일기는 Drive에만 있습니다 —
> (b) `python3 scripts/build-diary.py` 로 만든 `dist/snap-diary` 폴더를 Netlify·Cloudflare Pages 같은 HTTPS 호스팅에 올리면 됩니다.

### 2. Google Cloud에서 OAuth 클라이언트 만들기 (약 5분)

1. <https://console.cloud.google.com/> 에서 새 프로젝트를 만듭니다 (예: `snap-diary`).
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API** 를 *사용 설정*합니다.
3. **OAuth 동의 화면**(Google 인증 플랫폼): 사용자 유형 **외부**, 앱 이름 `스냅 다이어리`, 이메일 입력.
   - **데이터 액세스(범위)** 에 `.../auth/drive.file` 하나만 추가합니다. (비민감 범위라 심사가 필요 없습니다.)
   - **게시 상태는 "테스트"로 두고, 테스트 사용자에 본인 Google 계정만** 추가합니다. → 다른 사람은 로그인 자체가 막히는 *폐쇄 앱* 이 됩니다.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**, 유형 **웹 애플리케이션**:
   - 승인된 JavaScript 원본: `https://siree1223-sys.github.io`
   - 승인된 리디렉션 URI: `https://siree1223-sys.github.io/snap/`
   - (주소가 다르면 앱의 **설정 → OAuth 클라이언트** 화면에 표시된 값을 그대로 복사해 넣으세요.)
5. 만들어진 **클라이언트 ID**(`…apps.googleusercontent.com`)를 둘 중 한 곳에 넣습니다.
   - `snap-diary/config.js` 의 `googleClientId` (모든 기기에 적용, 권장), 또는
   - 앱의 **설정 → OAuth 클라이언트** 칸 (그 기기에만 적용)
   - ⚠️ 모든 기기에서 **같은 클라이언트 ID**를 써야 합니다. `drive.file` 권한은 "이 클라이언트가 만든 파일"만 보이므로, 다른 ID를 쓰면 다른 다이어리처럼 보입니다.
6. (선택) 더 단단히 잠그려면 `config.js` 의 `allowedEmails` 에 본인 Gmail 주소를 넣습니다.

> 클라이언트 ID는 비밀값이 아닙니다(브라우저 앱에서는 원래 공개됩니다). **클라이언트 보안 비밀(secret)은 절대 넣지 마세요** — 이 앱은 쓰지 않습니다.
> 테스트 상태 앱은 로그인 때 "Google에서 확인하지 않은 앱" 경고가 나올 수 있습니다. 본인이 만든 앱이므로 *계속* 을 누르면 됩니다.

### 3. 휴대폰에 설치

- **안드로이드(Chrome)**: 앱 주소 열기 → 메뉴 ⋮ → **앱 설치**(또는 홈 화면에 추가). 설정 화면의 *홈 화면에 설치* 버튼도 됩니다.
- **iPhone(Safari)**: 앱 주소 열기 → 공유 버튼 → **홈 화면에 추가**.
  홈 화면 앱에서는 Google 로그인 팝업이 잘 돌아오지 않을 수 있어, 기본값으로 **페이지 이동** 방식 로그인을 씁니다(설정 → 로그인 방식에서 바꿀 수 있음).
- 설치 후 **설정 → Google 계정 연결** 을 누르면 `Snap Diary` 폴더가 Drive에 만들어지고 동기화가 시작됩니다.

## 사용 팁

- 오른쪽 아래 **＋** 로 새 기록. **장소 사진 (3D)** 로 올린 사진은 바로 깊이 계산을 시작합니다. 일반 사진도 *3D로 만들기* 로 바꿀 수 있습니다.
- AI 깊이 모델은 처음 한 번 수십 MB를 내려받습니다(이후 캐시). 모바일 데이터가 걱정되면 **설정 → AI 깊이 추정 사용** 을 끄면 간이 깊이를 씁니다.
- Google 로그인 토큰은 보안상 약 1시간마다 만료됩니다. 위쪽 동기화 표시가 *Drive 연결* 로 바뀌면 한 번 눌러 주세요. 그동안 쓴 기록은 기기에 안전하게 저장되어 있다가 연결되면 올라갑니다.
- PIN은 화면 잠금입니다. 1분 이상 다른 앱에 있다 돌아오면 다시 잠깁니다. 기기 저장소를 암호화하지는 않으니 휴대폰 자체 잠금도 꼭 쓰세요.
- PIN을 잊으면 잠금 화면의 *PIN을 잊었어요* 로 이 기기 데이터를 지우고 다시 Google 계정을 연결하면 Drive에서 복원됩니다(아직 동기화 안 된 기록은 사라집니다).

## 한계 (솔직하게)

- 사진 **한 장**으로 만든 3D라서, 많이 돌리면 앞 물체 뒤쪽(사진에 찍히지 않은 곳)이 빈 틈으로 보입니다. 그래서 회전 각도를 제한해 두었습니다.
- AI 깊이 추정은 휴대폰 성능에 따라 수 초~수십 초 걸릴 수 있습니다. 한 번 계산한 깊이는 Drive에 저장되어 다른 기기는 다시 계산하지 않습니다.
- 개발 환경에서는 가짜 Google Drive·가짜 로그인·가짜 AI 모듈로 브라우저 자동 테스트를 했습니다. **실제 Google 계정 로그인, 실제 AI 모델 다운로드/추론, 실제 휴대폰(특히 iPhone 홈 화면 앱)에서의 동작은 직접 확인이 필요합니다.**

## 개발

빌드 도구가 필요 없는 순수 ES 모듈입니다.

```sh
npm run test:diary        # 데이터 모델·/snap 그레인 이식·깊이·동기화 엔진 (Node 22, 의존성 없음)
npm run build:diary       # dist/snap-diary 생성 (서비스 워커 캐시 버전 스탬프)
npm run test:diary:e2e    # 실제 Chromium에서 두 기기·오프라인·PIN·3D 렌더링까지 (playwright 필요)
```

| 파일 | 역할 |
| --- | --- |
| `js/place3d.js` | 3D 장소 뷰어 (WebGL 그레인 셰이더, 궤도 카메라, 자이로, 스냅 애니메이션) |
| `js/grain.js` | Meet Vanish에서 이식한 그레인 해시·분리 시점·그리드 계산 |
| `js/depth.js` | AI 깊이(Transformers.js + Depth Anything V2) / 간이 깊이 |
| `js/sync.js`, `js/drive.js` | Google Drive 동기화 엔진, REST 클라이언트 |
| `js/auth.js` | Google 로그인 (팝업 / 페이지 이동), 허용 계정 확인 |
| `js/store.js`, `js/repo.js` | IndexedDB 저장소, 원자적 로컬 쓰기 |
| `js/app.js`, `js/ui.js`, `js/lock.js` | 화면, 라우터, PIN 잠금 |
